# Платформа объявлений (Ad Platform API)

## Общее описание проекта

Платформа объявлений - это REST API приложение для размещения и управления объявлениями. 
Проект представляет собой бэкенд-часть веб-приложения, аналогичного Avito или Юла.

### Основной функционал:
- Регистрация и аутентификация пользователей
- Управление объявлениями (CRUD операции)
- Добавление и управление комментариями
- Загрузка изображений для объявлений и аватаров пользователей
- Разграничение прав доступа (USER/ADMIN)

## Используемые технологии

### Backend:
- **Java 17** - основной язык программирования
- **Spring Boot 3.1.0** - фреймворк для создания приложения
- **Spring Security** - аутентификация и авторизация
- **Spring Data JPA** - работа с базой данных
- **Spring Validation** - валидация входных данных

### База данных:
- **PostgreSQL** - основная база данных

### Документация API:
- **OpenAPI 3.0** - спецификация API
- **Swagger UI** - интерактивная документация
- **Springdoc OpenAPI** - интеграция Spring Boot с OpenAPI

### Маппинг:
- **MapStruct** - преобразование DTO ↔ Entity
- **Lombok** - уменьшение шаблонного кода

### Сборка и зависимости:
- **Maven** - управление зависимостями

### Тестирование:
- **Postman** - ручное тестирование API
- **JUnit** - модульное тестирование (планируется)
